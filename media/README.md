# Voice media

These recordings are the minimum matching-voice vocabulary used by MyAWOS
Lite. The software source is MIT-licensed; distribution rights for the voice
recordings remain with the MyAWOS project owner and are not automatically
granted by the software license.

`WeatherStation_no_weather_available_at_this_time.wav` is the fail-safe message
used whenever the current observation is missing or too old. Replace the
included synthesized clip with a recording of the exact phrase in the normal
MyAWOS voice when one is available; keep the filename unchanged.
